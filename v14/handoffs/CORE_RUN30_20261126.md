## Code change

`v13/code/v13/native_receiver_matrix_runtime.py` now performs a cheap model-route liveness check for persisted one-shot matrix approvals. It compares the recorded sender/receiver model revision, canonical selected path, regular-file type and stat identity (device, inode, size, mtime_ns, ctime_ns). Drift is classified as `STALE_MODEL`; the existing invalidation path can revoke/clear it. This prevents a replaced model from leaving an approval indefinitely reported as PENDING.

The liveness check deliberately does not hash the GGUF. That would make status/clear expensive on mobile. The actual native run still calls the existing full `_model_bindings` / manifest verification before the receiver is invoked. No approval authority, training authority, production route or B3 status changed.
