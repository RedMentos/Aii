## New runtime path

The native receiver diagnostic matrix now has 13 conditions. `SELF_GENERATED_MESSAGE` is generated by the same receiving llama.cpp model from the same bounded source prompt. Greedy decoding produces one hidden-state row per generated token, with the generated row count equal to the sender candidate's baseline-plus-candidate row budget. Those hidden rows are re-injected into the same receiver embedding interface, then the unchanged target continuation is scored.

The request binds receiver-model SHA, prompt-token SHA/count and row budget. The native receipt binds the actual float32-le hidden-row SHA, generated-token SHA/count, decode status and KV snapshot. Raw text, token IDs and hidden vectors are not persisted.

The utility layer adds `SELF_SUBSTITUTION_GAP` as a paired target-token logprob delta between sender candidate and receiver-self message. This is a likelihood proxy, not task accuracy. It does not prove separate-agent value, trained cross-model latent communication or B3 acceptance.
