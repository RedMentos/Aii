# Run44 — offline read-only V13 Store B2 rule/eligibility SHADOW CLI prereg (2026-10-28)

**Parent:** Run43 review-only #951 at `ce4b22d813ce337eb7b62fa158fda440c0554df6`. This prereg precedes Run44 source and tests. No production Runtime/Store/cognition, canonical blueprint, frozen native cohort or model changes.

**Motivation:** Run39–42 are isolated functions, not directly inspectable against an installed V13 home without creating a Runtime. Constructing `Runtime` or `Store` for a diagnostic is unsafe: the production Store constructor acquires a coordinator lock, changes WAL/journal mode, runs migrations and recovery writes. A safe diagnostic must never instantiate them.

**Candidate:** new `scripts/run44_b2_shadow_readonly_cli.py` accepts `--installed-home`, `--event-id`, `--model-revision`, `--out`. It opens only the existing `data/db/brain.sqlite3` in SQLite `mode=ro&immutable=1` with `PRAGMA query_only=ON`, refuses a nonempty WAL or an actively held coordinator lock (offline/quiescent prerequisite), never creates a file under installed-home, and implements the narrow `one`, `rows`, `read_source` interface required by Run40/42. Blob reader verifies original `sources` table hash, tombstone, bounded uncompressed or archived zlib blob and exact character offsets. Refuse symlinks, malformed SHA, missing DB/source, non-quiescent state, invalid input/event, output overwrite and output inside installed-home. JSON output contains typed SHADOW decision and source IDs/hashes only, never raw source text, and no authority or canonical gate promotion. The command is offline-only; live concurrent reads and Redmi execution are not claimed.

**Tests:** create a real temporary V13 Runtime home with synthetic B2 offers, close it normally, then invoke the CLI as a read-only view and compare Run42 result with direct Store-based software output. Assert exact byte hashes of database/blobs and directory listing unchanged before/after, and reject active coordinator lock, WAL, tampered source, deleted source, malicious output path, and missing event. Test both uncompressed and archived zlib source. Preserve failed attempts and original raw.

**Proof:** source-only focused tests and full suite with pinned deps, privacy/diff, raw exit logs and SHA256SUMS. No native model, no automatic user output, no learning, no tool execution. All original negative gates remain: Age0 RECORD_ONLY; STEP2 UTILITY_FAIL; B3 L1 FAIL; Body-JEPA UNAVAILABLE; LP3 FAIL; jepa_weight=0; Redmi UNMEASURED; V13 incomplete. Remaining platform budget UNKNOWN.
