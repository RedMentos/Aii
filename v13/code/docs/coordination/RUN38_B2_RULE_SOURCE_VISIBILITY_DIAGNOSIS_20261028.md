# Independent B2 source-visibility diagnosis from original Run26 raw (2026-10-28)

**Not a patch or gate promotion.** This analysis uses the immutable original Run26 Keldara Linux-native Actions artifact `12826794972`, original ZIP SHA256 `989abb8ac7b8fcd91ec047f97b735c9c8f84342e49251855b3375f7b3519762b`, CRC PASS. It does not rerun or alter Run26/Run32, registered seeds, model files, weights, runtime defaults, source selection or failed evidence.

**Observed in `STEP2_RAW.json`, `both_exact` arm:** B2_GIST's `offer.quotes=[]`, `evidence_refs=[]`, `confidence=0`, `needs_reentry=true`; no verified rule quote reaches C3. The B2 `context_source_refs` contain **only** a 240-character beginning of the latest supplier sheet and an 85-character **Project Quasar archive index**, which explicitly says it contains no active rules. Neither source is the earlier binding Keldara project rule. The B2 native prompt thus did not receive that earlier rule via `earlier_context` in this arm. Its summary begins with a Keldara source description and stops; absence of rules in its context is an upstream visibility failure, not evidence that B2 saw and ignored the rules.

**Mechanism candidate:** `v13/cognition.py:body_context` iterates `retained_offer_ids` newest-first, truncates to `b2_state_slots`, checks same-session/generation/model and topic relatedness, takes the first 240 source characters, and skips additions exceeding `b2_context_chars`. The recent supplier intro and a Quasar archive note can occupy the bounded context ahead of the earlier binding rule. `cognition.offer` then passes only `body_context` excerpts as `earlier_context` to B2. This is not a proof of the exact eviction cause without a controlled replay; it identifies a concrete visibility precondition that failed in the original raw.

**Separately observed C3 limitation:** Run36 Velaris C3-only native test *did* deliver source-exact B2 rules, but B1_B2_EXACT and B1_ONLY produced byte-identical wrong action/remaining answers. Therefore two distinct bottlenecks must not be conflated: **B2 source retrieval/quote production** and **C3 use of delivered rules**. Run37 isolates the latter with a new disjoint prompt factorial, but it does not fix the former.

Keep hard limits, source revocation checks, same-generation/model/topic constraints, decoy negative controls, immutable source refs, quote verification, and no silent fact promotion. Primary measures: earlier-rule source present in B2 query, exact rule quote verified, and downstream action/remaining field correctness.
