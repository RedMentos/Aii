# Run40 — read-only Store historical B2 offer adapter prereg (2026-10-28)

**Parent:** Run39 review-only PR #947 exact source head `a56bad5ea73b72150b8af099d3be1638d4afda2e`. This prereg precedes Run40 implementation/tests. No production Runtime, Store schema, frozen SourceHandoff, original TP/s27, Run12b, Run33–37 or native models modified.

**Motivation:** Run39's source-only selector can search up to 32 historical offers but requires an explicitly supplied source-verified history. Current B2 retained state stores only four recent offers. Without a real read-only historical source adapter, the new selector cannot see an evicted older rule in a live database.

**Candidate:** `scripts/run40_b2_store_history_readonly.py` exposes a non-integrated read-only `collect_history(store, current_event, session, generation, model_revision, limit=32)` and `select_from_store(...)`. Use only existing `Store.one`, `Store.rows` and `Store.read_source` methods; never construct Store, update state, create events, log, or touch a native runner. Bound a SQL query to 256 rows and output at most 32 verified B2 offers. Tie every offer to its event/session/generation/model, original event source ref and event sequence; require offer creation before current event creation, refuse future events, duplicates, malformed packets, deleted sources, changed hashes and mixed-generation history. Source text is read only through the original integrity-enforcing callback. Run39 remains SHADOW and receives no model or decision authority.

**Primary software acceptance:** real in-memory SQLite with the actual `events` and `packets` column layout: older rule beyond retained slots is recoverable and its exact 240-char source span passes Run39; current/future/cross-session/generation/model offers, late-completed old offers, duplicate events, invalid event/source refs and deleted sources never enter candidate context. Verify SQL statements are SELECT only and no database rows change. Tests must not require native inference or network. Add source-only workflow with focused tests, compile, frozen parent hashes, privacy and diff; preserve raw exits and SHA256SUMS. This is a software bridge, not a live runtime integration or native utility result.

**Negative gates:** Age0 RECORD_ONLY, STEP2 UTILITY_FAIL, B3 L1 FAIL, Body-JEPA UNAVAILABLE, LP3 FAIL, jepa_weight=0, Redmi unmeasured, whole V13 incomplete. Fresh preregistered native B2+C3 comparison, exclusive owner and permission-aware integration remain prerequisites. Platform budget UNKNOWN.
