**Motivation:** Frozen n64 synthetic SQLite row-shuffle result #775 found no action-specific incremental JEPA gain; row-shuffle beats correct for both seeds. Its state/outcome relation is nearly linearly predictable without actions. This new cohort tests whether a fixed nonlinear *action × state* outcome signal can be learned, not whether the old negative result was wrong.

**Fixture frozen before implementation:** exactly 48 distinct states, each paired with each of the four `wm.ACTIONS` (192 rows). For state index `i=0..47`, `x=i/47`, state `s=[0.25+1.25*x, (i%3)/2, sin(2*pi*(i+0.5)/48), cos(2*pi*(i+0.5)/48)]`. For action index `a=0..3`, outcome `y=[0.2+0.15*x+0.12*a+0.2*x*(a/3)+0.05*(s[2]+1), float((i+2*a)%7 != 0), 0.3+0.08*(a+1)+0.25*(x-0.5)**2*((a+1)/4)+0.02*(s[3]+1)]`. Synthetic action IDs `matched-s{i:02d}-a{a}`, row order state-major then action. All finite/in-domain. For each state exactly one action held out: `a_hold=(3*i+1)%4`, yielding 144 train and 48 heldout, each action held out 12 times. **States deliberately overlap** between train/heldout; state-action *pairs* do not. No claim of novel-state generalization. Do not use `wm._split` here; this is a new separately registered split.
