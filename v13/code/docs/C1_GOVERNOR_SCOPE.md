# C1 continuity and source-bound response governor

Implements the existing Canon §§3.3.4 /4.5 explicit executive state and §1.6 fallback snapshot. This is a bounded structured state outside the interchangeable language model, not a native KV projection or trained executive model.

C1 stores eight recent immutable goal/event references, an explicit active task, current approved operator constraints, current action/corollary IDs, current source-bound memory references, A/source and B/hypothesis references, unresolved hypothesis tags, actual resource measurements, and current Age-0 permissions. Task completion is not inferred from a fluent model answer. Tasks remain unconfirmed until the operator replaces or clears them. Every view rechecks immutable sources, active memory scope and supersession. Versions and state packet publication move in one SQLite transaction. Sessions remain isolated across restart.

The C2 boundary keeps the native raw query unchanged, preserving the measured calibration protocol. A typed executive control context is checked around the native invocation for exact request/session/generation binding, source validity, state version, constraints, permission and resource guard. The structured view is consumed by this policy boundary; it is not claimed to be injected into a hidden native Needle context port. Allowed model proposals only select existing local processing routes. Model text never gains command execution or external action permission.

The response governor prepares an immutable source snapshot before deliberation and refreshes it after validated memory recall. A forced report or failure before a native output can render the accepted input and applicable exact human corrections immediately. It is explicitly labelled `SOURCE_SYSTEM_REPORT; Systemdiagnose; keine Modellantwort`. It makes no calculated, inferred or invented answer claim, and does not promote B offers, generated answers, teacher text or hypotheses into facts. Existing native partial outputs remain native partial outputs. An actual full semantic answer is still dependent on the existing native report path.

Runtime and operator integration are implemented: `:executive`, `:task set Text`, `:task clear` and `:force-report`. The native report prompt consumes explicit active-task, current action, permission and unresolved-hypothesis fields with durable source lineage. Eleven behavioral tests pass in `docs/proofs/executive-unit-20261004.log`; these tests are structural/unit and missing-model runtime evidence, not a native or Redmi proof. Existing native collectors validate the expanded state-version chain. Native KV persistence, trained JEF projections, neural uncertainty calibration and task-completion inference remain unavailable here.

`tests/integration_executive.py` collected `EXECUTIVE_CONTINUITY_PASS` (11/11 checks) in `docs/proofs/executive-native-20261004.json`: actual unchanged Needle control, two real C3 reports without a B manifest, task-source consumption, actual action/corollary binding, exact restart, frozen weight hashes, and immediate best-output rendering. This Linux proof contains captured source hashes and is historical when later source changes occur; the complete current acceptance collector must be rerun.
