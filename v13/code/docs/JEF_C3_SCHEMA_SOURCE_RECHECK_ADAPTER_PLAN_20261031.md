# JEF→C3 native JSON-schema source-rechecking adapter — engineering plan (2026-10-31)

**Owner:** GPT-6 scheduled continuation. Review-only child of Run68 PR #1428 exact `4b14ca3bea9b4ddf717aefb7d04408d4b59921b5`. No production Runtime/CLI source changes, no original cohort/model/seed/pin changes. Run68 original 6/6 schema-vs-2/6 baseline **formatter-copy** diagnostic is preserved and not a general semantic-quality proof. This package implements an additive **default-OFF SHADOW software adapter** for source-verified typed JEF actions and JSON-schema output, not native model execution or output authority.

**Contract frozen before code:** Accept `memory, session, event_id, current_ref, exactly two memory_ids, generate(messages,schema)`; `operator_opt_in` and `callback_opt_in` must be exact Python `True`. Any approval receipt is unsupported. Before callback, use unchanged `build_jef_c3_typed_envelope` to revalidate current latest USER, two exact F1/F5 source refs and JEF action. Deep-copy original messages and frozen schema before passing to callback; no caller-supplied oracle. Frozen schema `{"type":"object","properties":{"action":{"type":"string","enum":["A","B","NONE"]}},"required":["action"],"additionalProperties":false}`. Parse bounded <=1024-byte strict UTF-8 JSON, duplicate-key reject, only one key, only uppercase A/B/NONE, no casefold/strip; compare parsed token with source-verified JEF action. After callback, independently rebuild the same source-verified envelope and require byte-identical `dumps` and message SHA; revoked, stale, foreign, changed source, changed USER event, callback mutation or re-entry race **fail closed**. Exception/nonstring/oversize/invalid JSON -> RED. Return only status, output hash, source hashes, source-only fallback flag, no raw source or model output. No Store writes by adapter; any callback is untrusted and **never** establishes native proof.

**Safety invariant:** `delivery_authority=0`, `output_committed=False`, `tool_dispatches=0`, `learning_authority=0`, `real_tty_approved=False`, `native_proof=False`, Age0 RECORD_ONLY, STEP2/B3/Body-JEPA/World-JEPA/jepa_weight/Redmi/whole-system negative. No C6 approval, no assistant FINAL, no TTY, no queued Sleep. Adapter may be used by a later separate real native SHADOW CLI, which must independently prove model/runner pins, process cleanup and C6 preflight.

**Tests:** frozen JSON schema parity with Run68, OFF/no callback, exact match, wrong action, duplicate/extra/nonfinite JSON, nonstring/oversize, callback exception, deep-copy mutation, stale latest USER, source forget/reapproval during callback, foreign/swapped refs, no new Store messages/actions. Use actual Store/Memory synthetic sources, never fake native execution. Software CI pins code/Canon and retains raw tests/CRC/SHA, privacy/diff. This is an engineering adapter package, not a new scientific cohort.
