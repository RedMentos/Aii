# Optional mid-layer receiver diagnostic

Close the installed chat and run `bash TESTEN_NATIVE_MIDLAYER.sh`; `--prepare-only` builds and runs typed guards without model inference. This separate test preserves the established final-norm receiver, observer and pause/resume paths.

Only the pinned C3 LFM2 model is accepted: actual architecture `lfm2`,14 layers,1,024 hidden dimensions,65,536 vocabulary entries. One sequence0 physical batch of at most128 exact template tokens selects only its final-token row. The target is exactly `l_out-6`; the next consumer must be the current `norm-7` node with `GGML_OP_RMS_NORM.src[0]` equal to that just-computed same-epoch tensor. Every other architecture, layer, consumer, row, sequence or epoch is refused.

The pinned source shows `l_out-6` feeding layer7 RMS normalization. The public scheduler finishes and synchronizes the requested source node before asking the next RMS consumer. The worker reads/hashes its final 1,024D row, validates a typed authored numeric vector and current tensor identity, then writes only that row to an actual host non-parameter COMPUTE buffer before RMS evaluation. Earlier-token prefix bytes must remain identical. The callback drops its source pointer when that consumer completes; native layers7–13 and output decoding then complete normally.

BOOT update bounds remain L2 at most0.125 and update/state ratio at most0.01. The reconstructed preregistered numeric diagnostic uses only the actual baseline state's norm: target L2 is `min(0.0625, baseline_state_l2 * 0.005)`, with alternating signs and coordinate magnitude `target L2 / sqrt(1024)`, encoded as F32. It uses no semantic scores or output-dependent tuning. Zero makes no write. Baseline/zero hidden state and full logits/probabilities must be byte-identical. Nonzero must produce exactly one bounded scratch-row write and a measured full-vocabulary effect. Greedy output change is reported, not required. Source snapshots, typed inputs, callback phase order, before/after/prefix hashes, complete outputs, model hashes, RSS/PSS and reaping evidence are retained for each fresh attempt.

The later fixed-amplitude native failure and baseline-norm scaled native run were not recovered with their raw evidence. Their native outcomes cannot be treated as durable proofs. This amended helper has non-native policy guards; its actual native rerun is pending, with no native cache or execution performed during reconstruction. The original prepared source snapshot remains unchanged.

This is an isolated optional BodyPort numerical interface. Compilation and guards do not prove the actual mid-layer effect; only a real run can. Even a numeric pass enables zero runtime/receiver authority and does not establish trained B3 communication, learned projectors, receiver utility/calibration, native weight training, improved latency, or Redmi performance.
