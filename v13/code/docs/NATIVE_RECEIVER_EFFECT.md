# Bounded receiver-effect diagnostic

After normal installation, close the chat and run `bash TESTEN_NATIVE_RECEIVER.sh`. `--prepare-only` checks/builds the worker and command guards without model inference. Completed and failed attempts remain in a fresh `$V13_HOME/exports/receiver-effect-<timestamp>/` directory, with raw vectors/logits/probabilities, source snapshots, exact tokens, typed numeric-source files, native logs, sampled RSS/PSS and process-reaping evidence.

This isolated existing-BodyPort test writes only one ephemeral selected **host F32 result_norm row**. It never writes model parameters. The verified b10964 scheduler completes and synchronizes requested `result_norm`, then asks for the current `result_output` node before computing its matmul. At that ask, the worker accepts only `GGML_OP_MUL_MAT` whose `src[1]` is the just-computed same-decode norm. Other topology, tensor type/shape/stride, non-host or non-COMPUTE buffers, parameter flags, stale frame, cancellation or missing identity stop the capability before any write. Public `ggml_backend_tensor_set/get` provide the bounded write and exact readback. No tensor pointer survives the decode.

The typed numeric fixture has explicit `AUTHORED_NUMERIC_DIAGNOSTIC` scope, a unique source ID and nonce, source-file hash, exact model/library/backend/token/context bindings, the exact original tensor hash, and 1,024 finite F32 coordinates. BOOT limits are update L2 at most0.125 and applied update/state ratio at most0.01; oversize updates fail instead of being silently clamped. Input JSON rejects booleans, invalid shapes/fields/hashes/names, duplicate keys and payloads beyond64KiB.

Three fixed variants use fresh processes/contexts: baseline, zero vector (no tensor write), and alternating authored +0.003/-0.003 coordinates. Baseline and zero must have byte-identical native state, full logits/probabilities and matching greedy token. Nonzero must make exactly one bounded scratch-row write and measure a nonzero full-vocabulary effect; the greedy token may remain the same. Raw before/after hashes, callback phase order, model hashes and full 65,536-entry output distributions show what actually happened. Each process unloads/exits and is reaped, resetting the ephemeral effect.

Source inspection and compilation establish the proposed hook, not the native effect. The actual test must pass before that effect is claimed. Even a pass has **zero production or receiver authority**: no learned projector, trained B3 bridge, useful semantic transfer, receiver calibration, native training, full Canon completion, latency improvement or Redmi performance is implied. The established observer/pause-resume workers and runtime remain unchanged.
