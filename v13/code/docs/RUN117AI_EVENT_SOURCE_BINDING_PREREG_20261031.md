**Read-only finding before implementation**: frozen `b1b2_source_id_quote_candidate._candidates` verifies that `event_id` is latest authoritative USER event in the session, but reads `event["source_ref"]` independently without checking it against the authoritative source_ref stored in that event's packet. A caller can pair the latest USER `event_id` with an earlier valid USER `source_ref` from the same session; when the earlier source has the required policy/archive anchors, B2 may select and persist a source-ID packet for the wrong event. This is a *source lineage integrity* issue, not an inference/model-performance claim.

**Isolated candidate**: add a default-OFF wrapper, not a patch to the frozen source/runner. Resolve the latest authoritative USER event through the existing `f1f5_event_finalizer_candidate._event_snapshot`, require the complete caller event SourceRef and generation to equal the canonical stored event, then invoke frozen `select` with separate operator/callback opt-ins. On successful frozen selection, recheck event/source and the persisted `BodySourceIdSelection` packet's event, role, generation, SourceRefs, candidate exact spans, output-authority flags and selected ID. Preserve wrong and abstained model selections as fallible; do not promote semantic truth. No native model invocation except a separately authorized trusted callback; no tools, delivery or learning.
