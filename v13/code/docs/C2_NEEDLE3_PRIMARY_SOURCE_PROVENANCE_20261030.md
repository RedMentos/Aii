Do not treat `native_control` metadata or a calibrated confidence claim as proof of STEP2 utility or an approved external action.

Third-party Rust API documentation describes the shipped C engine as process-global/non-thread-safe; V13 conservatively uses a single serialized Needle worker and reaps it. The model's Apache-2.0 metadata **must not be generalized to all bundled binary engines, training data, or other artifacts without separate license inspection**. Preserve each binary hash/provenance and do not upload downloaded models or private evidence.
