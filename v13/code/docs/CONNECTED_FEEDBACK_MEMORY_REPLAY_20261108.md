# Verbundener Feedback-, Gedächtnis- und Replay-Test

Isolierter Integrationszweig auf der C5-Ledger-Kette #1608 (`15c7a4f5f1961280e2cb0f78746ead3adfc2c39f`). Dieser Test führt die quellgebundenen C5-Outcome- und F1/F5-Assoziationskandidaten zusammen. Er materialisiert `runtime.py`, `neuromod.py`, `memory.py` und `episodes.py` nach Quellhashprüfung in einer separaten Runtime-Kopie; die eingefrorenen Originale und registrierten Kohorten werden nicht verändert.

Ein synthetischer Nutzerturn ruft eine bestehende F1-Erinnerung ab. Eine menschliche F5-Korrektur zu diesem Turn erzeugt eine neue Erinnerung und einen Replay-Eintrag; eine ausdrückliche Bewertung desselben Turns erreicht den echten C5-Feedback-Hook und, nach bewusstem Einschalten, den quellengebundenen SHADOW-Ledger. Sleep A prüft den Korrekturbezug. Bei einer Folgefrage, die nur die ursprüngliche Erinnerung direkt abruft, meldet der neue episodische Consumer die Korrektur als zusätzlichen **SHADOW-Kandidaten**. Eine Vergleichsausführung mit beiden Ergänzungen aus liefert diesen Kandidaten und den neuen Ledger-Eintrag nicht.

Die Probe prüft außerdem, dass der C5-Kandidat eine abgeschlossene Antwort nicht automatisch als fachlich richtig bewertet, dass die menschliche Korrektur im bestehenden C5-Pfad ankommt, dass der SHADOW-Ledger und der episodische Vorschlag nach Neustart erhalten bleiben und dass ein gezielter Assoziations-Rollback den Vorschlag entfernt. Ein zusätzlicher Arm ohne Bewertung zeigt, dass das menschliche Feedback den später im ActionSelection-Paket ausgewiesenen C5-Score-Vorschlag für `C3_LANGUAGE` in diesem Szenario senkt. C5 bleibt auf SHADOW und die tatsächlich gewählte Aktion entspricht der unveränderten BOOT-Auswahl. Die Nutzerantwort bleibt in allen Armen gleich; `RECORD_ONLY` bleibt gesetzt, es werden keine Gewichts-Updates geschrieben. Andere Tests prüfen insbesondere Replay-Ablation und Quellenwiderruf.

Ausführen von `v13/code`: `PYTHONPATH=.:tests python -m unittest test_connected_feedback_memory_replay_20261108 -v`. Die Probe verwendet den echten Runtime-/SQLite-/Memory-/Sleep-Pfad mit einer synthetischen C3-Ausgabenaht. Sie belegt verbundenen Datenfluss und persistente SHADOW-Zustände in diesem Szenario; sie belegt **nicht** semantische Relevanz der Assoziation, eine Verbesserung einer echten Modellantwort, JEPA-/Body-Gradienten oder einen Redmi-Lauf. Vor einer Beförderung bleiben frische Relevanzkontrollen, Retention, atomare Quellenprüfung am Consumer und die Behandlung alter Feedback-Mittelwerte offen.
