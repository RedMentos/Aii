# Causal prefill pause/resume diagnostic

Install normally, close the chat, then run `bash TESTEN_NATIVE_SESSION.sh`. Use `--prepare-only` to verify/build and run command guards without model inference. Each attempt uses a fresh directory under `$V13_HOME/exports/prefill-session-<timestamp>/`; `--out-dir` chooses another fresh directory.

This adjacent worker reuses the established BodyPort observer source unchanged. It performs real causal prefill once, saves the 1024D final state and full computed 65,536-entry native logits/probabilities, and pauses that same CPU context. Its one-use handle binds a fresh nonce, native PID, model/library/backend hashes, exact tokens, context-source hash, feature-file hash, sequence and next position. A bounded JSON resume command supplies at most16 unique vocabulary rows with finite numeric bias magnitude at most12. Stale, mismatched, expired, duplicate claims, malformed/duplicate-key JSON, booleans and invalid rows fail before continuation. The handle expires after15 seconds; cancellation and worker/parent deadlines bound waiting and decoding.

Two authored numeric fixtures are preregistered: zero bias, and a bias applied to the actual second-highest native row large enough to change the first greedy token (only when the needed value is at most12; otherwise the attempt fails). After that first token, three actual decode steps use unmodified native logits in the same context. The worker accepts one command, does not reload the model or re-prefill, and exits with actual process-reaping evidence from the controller. It keeps raw artifacts and exact compiled C++/helper source snapshots. The standard runtime and established five-pair observer test remain unchanged.

This is a runnable diagnostic protocol, with zero production or approval authority. The numeric delta is explicitly authored test data, not a learned adapter. Existing embedding-mode learned-head compatibility, quality, latency improvement, persistent KV, receiver injection, native training and Redmi validation remain open.
