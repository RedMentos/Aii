# Delta-JEPA primary-source scope and V13 negative transfer — 2026-10-28

**Primary source checked:** Zhenghao Zhang et al., *Delta-JEPA: Learning Action-Sensitive World Models via Latent Difference Decoding*, arXiv:2606.31232, submitted 2026-06-30, updated 2026-07-01, https://arxiv.org/abs/2606.31232 (accessed 2026-10-28). The arXiv distribution permission is not a code/model license. No external source code, pretrained weights or licensed assets were copied or installed for V13 Run67/69. Original V13 frozen source hashes and registered seeds are preserved.

**Paper claim, not a V13 result:** the paper's Latent Difference Action Decoder reconstructs an executed action from `z(next)-z(now)` instead of concatenated endpoints. The abstract reports improvements on four visual continuous-control tasks with a reconstruction-free prediction/action-decoding objective. These findings do **not** establish performance on V13's 60-feature isolated filesystem observations, discrete two-hot operation+slot actions, its small NumPy architecture or its train-only supervised outcome readout.

**V13 candidate scope:** Run67 #974 replaces only the inverse head's input geometry in the existing V13 training loop, preserving V13's variance/covariance penalties and original optimizer settings. It is an *inspired candidate*, **not a faithful reproduction** of the paper's complete architecture/objective or its continuous-control benchmarks. Exact original Linux software Run67 artifact SHA256 `9d5249f2b2743dc9f6dc6563853bf8f997514e1bcaee349665538acffa287c38` is independently verified (20/20 hashes, 35 focused/2617 full OK). Run67 observed-action delta MSE `0.135611` is worse than its zero-action `0.132357`, persistence `0.052773`, and slot-local ridge `0.016274`; retain this **negative grounded outcome**.

**Next discriminating question:** Run69 #976 preregisters four real heldout actions executed on copies of the *same* isolated file source state, with oracle/blind and supervised controls. This tests action-conditioned paired observed-outcome discrimination; it is not a planning benchmark, causal intervention on a real user environment, learned JEPA-only utility or a Redmi test. A favorable paired metric cannot overrule the original negative MSE or promote any canonical gate.

**For and against adoption:** latent-displacement action decoding offers a plausible inductive bias; however, original V13 toy-file measurements show no generalization gain, and action labels may correlate with stochastic file content rather than predictable outcome geometry. Require new preregistered heldout utility, action-ablation and retention evidence before considering a different implementation. Keep Age0 SHADOW and jepa_weight=0.

**Missing:** independent licensed source-code implementation, comparable continuous-control datasets, real Body train-runner, Redmi sustained measurements and the complete §100 acceptance gates. No new model revision is selected by this note.
