## Goal and source
Consume **only** `world_model.transitions(store)`, which reads finalized V13 digital action/outcome records from the existing SQLite store. Each source row has `action_id`, pre-action `s` (4 normalized observed features: input length, pressure, time sin/cos), selected route `a` in `simple|detail|gist|both`, and post-action observed outcome `y` (log duration, success 0/1, log output chars). Reject malformed/nonfinite values, duplicate action IDs, unknown routes, non-binary success, negative duration/character features. Require >=32 distinct transitions. Never use user chat text, model-generated future outcomes, unverified dream hypotheses, or stored learned_latent_prediction as ground truth.

Define **explicit observed post-action outcome packet**, not an exogenous next-world state: 8D `X=[s0,s1,s2,s3,0,0,0,0]`, `X2=[s0,s1,s2,s3,y0,y1,y2,1]`, action one-hot `A` in the four frozen routes. The final flag distinguishes pre/post observations; it is an encoding convention, not an extra observed fact. This is a narrow *digital action-outcome* JEPA path; do not claim that it models physical world state or future user inputs.

## Frozen experiment and heldout proof
Use existing `world_model._split(n)` deterministic train/heldout index partition **before** fitting, with train/heldout row-id digests. Model seeds **3,7**, ensemble **3**, **400** steps, unchanged `WorldJEPA` optimizer/EMA/hyperparameters. Train only on train X/A/X2. On training rows only, fit a ridge readout from `[1, target_encoder(X2)]` to observed y, ridge lambda **0.1**. Heldout y estimate is `[1, predictor_mean(X,A)] @ readout`. Compare heldout mean absolute error to (a) fixed ridge direct `[1,s,A]` -> y trained on same train split with lambda 0.01, (b) constant train-mean y, and (c) wrong-action `(a+1) % 4` predictor with the same frozen readout. Record per-target MAE and pooled scalar. No threshold for improvement, no optimizer tuning or seed selection after results. Any comparison is observational and confounded by route selection, not causal intervention.

No persistent weights, live routing, tool execution, Age promotion or automatic training. `run_store(store)` must be read-only, and return aggregate metrics/hashes only; never export source row IDs, source text, raw observations, trained model weights or private data. Synthetic fixture tests may run in public Actions, but no actual private user-store rows in GitHub. Separate opt-in device/private-store measurement and persistence/restart path required before claiming implemented live World-JEPA.
