# WP-BP1 paired native-C3 consumer scoring — prospective software protocol (2026-10-27)

**Base and ownership:** branch `codex/gpt6-bp1-paired-scoring-20261027-0905` from verified PR #677 head `74d84d06b9ed99041146a45ce35a0627a4beec28`. New scorer `v13/code/scripts/bp1_paired_score.py`, its tests, dedicated CI workflow, and this scoped proof only. No edits to frozen BP1 dataset, native models, runtime, sources, or existing experiments. Reviewer may inspect independently.

**Question:** Can a future selected C3 model consume native B2 offers in source-supported answers rather than merely mention a key? This package creates a deterministic **post-inference scorer**, not model training/inference or a positive gain claim. It must not train or tune on heldout targets.

**Immutable inputs:** BP1 PR #677 source report SHA256 `ea379b52c7b95c2bb30cd6725f539f443521a64210fdf6bf6fa726c413126880`, dataset schema `V13_BP1_C3_CONSUMER_DATASET_PREFLIGHT_V1`, `heldout_paired.jsonl` SHA256 `7238a0220255cbccbcf1f9ccfad8dc03febfc37f7bc1d9d0aa645618f006508c`; 11 heldout sources / 22 paired arms, projects disjoint from 25 training rows. B2 offers are untrusted. Do not alter the split, sources, original target, or model/seed registrations.

**Predictions contract (future native run):** a JSONL file with exactly 44 rows, each `model` (`base` or `candidate`), `row_id`, `arm` (`no_offer` or `offer`), `source_sha256`, `prompt_sha256` (hash of UTF-8 prompt), and `response` (raw C3 assistant string). Every model/row/arm appears exactly once, no duplicates or unknown keys. Separate binding JSON must contain pinned distinct model SHA256s, deployed GGUF SHA256s, runner SHA256, source/seed/decoding protocol and immutable dataset SHA256; metadata is reported as operator-provided, **not cryptographically proven model execution**. The scorer rejects malformed/incomplete inputs; it does not generate predictions.

**Scoring:** strict JSON object with only string `answer`, `evidence_quote`, `uncertainty`; reject duplicate keys, non-finite numbers, malformed or fenced output. Supported correct = answer key is exactly the answer (case-insensitive, surrounding whitespace allowed), evidence quote nonempty exact substring of original source, and answer key appears in that quote as a token. Unsupported nonempty answer is counted as unsupported commitment. Report per model and arm supported count, invalid quote count, abstentions, unsupported commitments, and within-model offer-vs-no_offer paired wins/losses/ties. Compare candidate to base within each arm, without statistical/promotion claims from 11 pairs. **Do not require evidence quote to be a B2 quote**: original source is the sole authority. Include fail-closed counterexamples for duplicate JSON keys, quote fabrication, unsupported answer, cross-arm mixup, missing/duplicate prediction, mismatched prompt/source hashes and tampered dataset.

**Acceptance for this software-only package:** Python stdlib unittest suite, compileall, official public-repo privacy scan CLEAN, GitHub Actions source-bound evidence with raw logs/exit codes and remote bytes checked. Synthetic scoring examples are not C3 native inference. Never mark STEP2, B3 L1, Body-JEPA, `jepa_weight`, Redmi or complete V13 as passing. No runtime or training activation.
