## Problem and hypothesis
The existing late-correction detector in `v13/code/v13/selfmodel.py` compares numbers in an observer offer against numbers in a completed answer; the recorded AGE0c result was `STAY_SHADOW` due to false alarms and lack of answer awareness. This candidate reads **the original user question and the actual completed answer** and checks only a narrowly recognized, deterministic arithmetic subset. It abstains on unrecognized questions or ambiguous answer formats. A verified mismatch is a diagnostic **candidate**; no message is sent and no Age permission is opened.

## Frozen protocol
Pure standard-library `decimal.Decimal` evaluator; no `eval`, models, network, tools, external actions, state mutation, telemetry free text or runtime hook. Accept exactly anchored EN/DE expressions with one binary operator from +, -, *, / (also x, ×, ÷), plus anchored EN/DE half-of phrasing. Numbers are signed integers or finite decimal literals, with decimal comma supported. Reject division by zero, exponent notation, multiple questions, prose containing embedded instructions, unrecognized units, nonterminating divisions, and ambiguous answers. Answer extraction accepts only an isolated number (optionally `Euro`/€) or a single anchored `Answer:` / `Ergebnis:` / `The answer is` / `Das Ergebnis ist` form. Never parse an arbitrary numeric substring from free prose. The output is `CORRECT`, `MISMATCH` or `ABSTAIN`, with no automatic correction/delivery.

Frozen evaluation: 12 explicitly enumerated correct rows, 12 wrong rows, 8 unsupported/ambiguous rows in the new unit-test file. The 12 wrong rows must be detected (criterion >=10/12), correct rows must have 0 false `MISMATCH` (criterion 0/12), and all 8 unsupported/ambiguous rows must abstain (criterion 8/8). Include tests for decimal comma, negative signs, zero division, multiple-number answer, adversarial appended instructions, and rounding ambiguity. Frozen rows are published in the test source; their SHA is to be recorded in closed evidence after implementation, never silently altered in later review.
