Problem: PR #754 has a read-only `run_store(store)` API but no safe local command to evaluate **actual finalized observed digital action/outcome transitions** in an existing V13 SQLite store. Its synthetic Actions 40560836649 showed JEPA readout pooled MAE 0.203321/0.192621 vs direct ridge 0.152555 (worse in both seeds); no utility promotion. This package makes local observation possible without giving the model live authority.

Design: explicit `--db PATH --ack-closed-store` only, no default mode, no network/model download, no file or model-weight writes. Refuse symlink DBs, missing/nonregular paths and WAL/SHM sidecars; user must close V13 and provide a quiescent SQLite DB or snapshot. Connect with `mode=ro&immutable=1`, set `PRAGMA query_only=ON`, open a read transaction, expose only `rows` and `one` SELECT methods to the existing `world_model.transitions` adapter. Never print source action IDs, user chat text or DB path; stdout only aggregate JSON from the already existing `run_store`. Catch malformed/missing/insufficient DB errors and print a sanitized nonzero status, without tracebacks containing private rows. No report file written by default.

Frozen software tests: construct 64 synthetic finalized action rows and ActionSelection packets in a temporary SQLite DB, verify existing World-JEPA adapter receives exactly these 64 transitions and returns scope `OBSERVED_DIGITAL_OUTCOME_SHADOW_NOT_NEXT_WORLD_STATE`, no runtime authority, no raw IDs, no DB byte/sidecar mutation; run smoke with steps=0 only (NOT a 400-step measurement). Verify invalid path, symlink, sidecar, missing schema, missing acknowledgement and too few rows fail closed. Focused CI, compile, privacy scan and diff check with closed raw exits. Full suite may be separate. No private DB or raw rows are sent to GitHub CI.

Evidence distinctions: synthetic SQLite smoke is software-only; **no actual private store run is performed by this automation**, no native LFM2.5, no Redmi, no causal future-world proof. No threshold or utility promotion. LP1 NO_ATTRIBUTABLE_GAIN, LP2 ALIGNS_NO_GAIN, BJ1 NO_SIGNAL, STEP2 UTILITY_FAIL, B3 L1 FAIL, jepa_weight0, Age authority0, V13 incomplete.
