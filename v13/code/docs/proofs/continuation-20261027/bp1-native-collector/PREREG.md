# WP-BP1 native C3 paired prediction collector — prospective preflight (2026-10-27)

**Branch:** `codex/gpt6-bp1-native-collector-20261027-0910`, child of review PR #678 source head `65e14c6b15a3cf992834b25daca851ee62d72d61`. Owner GPT-6, new runner/tests/workflow/scoped proof only. This is a **tool for a future native run**, not authority to launch a heavy run concurrently with other owners. No changes to existing frozen runtime, model registry, original Run181/BP1 datasets, learning/age gates, or active training cohorts.

**Goal:** Collect base and candidate C3 native llama-server outputs on exactly the preregistered BP1 heldout source pairs with no oracle/target in the model request. Each model receives both `no_offer` and `offer` prompts, exactly 11 each, temperature 0, fixed seed and response schema. Run one server/model at a time; never run two heavy native jobs concurrently. The runner does not train, select a model, change weights, download files, or activate C3.

**Input bindings:** require the exact BP1 heldout dataset SHA256 `7238a0220255cbccbcf1f9ccfad8dc03febfc37f7bc1d9d0aa645618f006508c`; a separately selected explicit `V13_BP1_C3_CONSUMER_EVAL_V1` JSON binding containing base/candidate master/deployed SHA256, runner SHA256, seed, temperature 0 and exact decoding recipe; verify deployed GGUF and llama-server bytes against the binding **before any native launch**. Master hashes are declared metadata, not verified master files by this inference-only runner; a separate training run must bind master bytes. Reject identical deployed base/candidate hashes. Require explicit `--serial-owner-confirmed` operator flag after checking no active heavy owner; no CI/model downloads.

**Output:** exclusive `RUN_BINDING.json` + fsync-per-row `predictions.jsonl` with exactly `model,row_id,arm,source_sha256,prompt_sha256,response` for 44 rows. Bounded raw response, fail-closed duplicate/unknown/mismatched records, source/prompt hash checks, atomic durable progress and restart from verified same binding. Each model's local server process is stopped and reaped before the next starts. On completion write exclusive final manifest with hashes, declared vs verified bindings, and negative gates. Keep raw server stderr private; do not upload to public git.

**Acceptance for this package:** software tests with fake request/serve (explicitly not native), source hash and resume counterexamples, compileall and privacy CLEAN; source-bound CI raw artifacts. Do not claim a native C3 run, learned utility, STEP2/B3/Body-JEPA/Redmi or full V13 completion. Next step is a separately preregistered selected C3 training protocol and a serial real-model run; run the BP1 paired scorer on its immutable 44-row output and retain baseline, candidate, near-miss and retention evidence.
