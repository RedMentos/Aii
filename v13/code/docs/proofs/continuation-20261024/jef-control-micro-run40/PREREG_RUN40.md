# Run40 preregistration — JEF/C2 multi-head synthetic control objective

Committed before training. Parent PR #75 195876c930eb93e1d509c4a577f330e55a6ebc71. Canon §3.4.6–3.4.9, §13H, §14.2. This is a CPU-only SHADOW scratch-model control experiment, NOT native C2, not C3, not a full JEF objective or authority.

Deterministic seed 20261024. Synthetic six binary features: exact_need, gist_need, conflict, resource_pressure, source_valid, urgency. Generate 512 training and 128 independent heldout rows from seeded Bernoulli sampling. Four-way route target direct/detail/gist/both from source validity, conflict, exact and gist flags; binary wake, halt and report targets from conflict, exact, pressure, source validity and urgency. All label functions are explicit and synthetic, not learned from model outputs. One shared 6->32 ReLU layer, four independent heads, Adam lr 0.03, 200 updates batch64, weighted route CE + three BCE terms, one CPU thread. Compare same-initialization untrained and shuffled-label negative control with identical minibatch order. Report heldout route accuracy and report Brier score; test each head's parameter update.

PASS_SYNTHETIC_ONLY criterion: route accuracy >=0.90, report Brier <=0.10, wrong-label route accuracy <=0.50, all four heads receive gradients and update, deterministic rerun, source/conflict hard gate prevents ungrounded report regardless learned score, Age0 action authority remains zero. Any failed criterion remains failed. No production weight writes, no automatic model routing, no B1/B2 suppression, no native tool use or gate promotion. Preserve raw failures and controls.
