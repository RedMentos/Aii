Missing/invalid evidence, question echoes, prose-only numbers and correct arithmetic must abstain or pass without a contradiction.

**Prospective tests:** true/false arithmetic, Decimal exactness, question echo, no `CALC:` marker, unbound operands, forged/dangling SourceRef, nonfinite/oversized input, duplicate late-offer calls, off/deliver mode exclusion and original Age0a late-correction regressions.
