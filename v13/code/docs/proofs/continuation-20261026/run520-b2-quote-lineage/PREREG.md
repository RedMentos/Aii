# Run520 prereg — B2 native raw-offer-to-verified-quote lineage guard (source-only)

Date 2026-10-26. Base Run519 PR #517 head `0e193755a446f837b848d143fcce582fa486979f`; Run519 p01 Linux-native one-shot has a separate serialized heavy owner and must not be mutated, restarted or interrupted. This package runs **source-only**, no model downloads, native inference or changes to frozen cohort.

**Observed integrity gap:** Existing Run513 postflight verifies each accepted `quotes[]` text and `evidence_refs[]` offsets against the four exact original sources, and checks that `rejected_quotes` is a nonnegative integer no greater than the number of `raw_offer_quotes`. It does **not** prove that the accepted source quotes correspond to any native model quote candidate in `raw_offer_quotes`. A fabricated but source-exact accepted quote can therefore pass source-ref verification and contaminate Run510 coverage. This is not a claim that original native artifacts were altered.

**Registered source-only test:** Construct original Run513 synthetic 12-row receipt; first confirm the original auditor passes; replace one `raw_offer_quotes` candidate with unrelated text while leaving valid source-exact `quotes` and refs; original source-ref check still passes, but the revised auditor must reject. Add controls for legitimate exact/pointer-expanded/casefold-whitespace candidate, empty candidate with no accepted refs, duplicate raw candidate with deduplicated refs, more accepted refs than available non-rejected candidates, and malformed types. Ensure `Run516` aggregate still replays Run513 and inherits the guard. Test must preserve original frozen Run509 fixtures, Run510 score, Run511 collector, Run512 source slots and all original negative gates.

**Design:** A bounded, deterministic, source-only lineage check associates each accepted quote with a **distinct** nonempty raw candidate whose whitespace-normalized, casefolded text occurs in the exact source-verified accepted excerpt. Since `offer_quote_context_chars=200` may widen the excerpt, strict byte equality would reject legitimate pointer expansions. Duplicated native candidates can collapse to one evidence ref; allow fewer accepted refs than candidate count. Reject impossible `accepted > len(raw)-rejected`. This guard proves candidate textual lineage, **not** that the model actually ran, not a semantic assertion, and not that all context choices were present in the native prompt. Do not rewrite historical evidence; new source revision gets its own SHA.

**Acceptance:** New adversarial tests plus existing Run509–518 source-only regression and public privacy scan in a SHA-pinned workflow. No gate promotion: STEP2 UTILITY_FAIL, B3 L1 FAIL, Body-JEPA UNAVAILABLE, jepa_weight=0, Redmi unmeasured, canonical architecture incomplete. Independent native receipt review remains required.
