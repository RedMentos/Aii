This protocol is committed **after** the independent 80-prompt cohort but **before** any Run608 code/model inference. Run606/607 results have been inspected and motivated this **new** experiment. It is not a repeat/extension of their frozen cohorts and must never be pooled into them.

Frozen new cohort: `RUN608_COHORT.json`, blob `f452bdf80bb8d8a784c1909c98e310041d3157aa`, 8 topics ×5 synthetic facts ×2 human-authored English paraphrases (80 distinct prompts); train topics transport/cooking/astronomy/gardening/finance/sports (60 prompts, 30 facts), heldout music/weather (20 prompts, 10 facts). Same-fact variants A/B are deliberately lexical and length variations; heldout topics/facts never enter the fit. This is a *small synthetic* semantic proxy, not real-world reasoning. No private data.

Use original public pinned Run606 native B1 LFM2.5-1.2B final-token 2048-dim and B2 Qwen3.5-0.8B final-token 1024-dim read-only taps and original llama runner/archive hashes; no new weights, injection or authority. Native capture each of 80 prompts once per body. Reuse exact native capture guards; bind token IDs, prompt SHA, role/dim/tap and model hash. No model-generated text. One fixed dual ridge map with L2 row normalization, train-only mean centering, alpha=1.0, no parameter tuning on heldout. Save raw state matrices for independent verification.

**Primary metric**: B1 state of each heldout variant A (respectively B) must retrieve the B2 state of its *opposite* paraphrase B (respectively A) from all 20 heldout B2 candidates; chance 1/20=0.05. Register success only if top1>=0.25, 200 shuffled-train-label controls empirical p=(1+count(null>=observed))/201 <=0.05, and advantage >=0.10 absolute over exact word-token Jaccard cross-paraphrase retrieval on the same frozen 20 queries/candidates. Ties broken by first fixed cohort order, no reranking. This is a difficult control: shared surface words can let lexical baseline outperform a learned latent mapping. If lexical wins, record FAIL without reinterpreting thresholds.

**Secondary metrics**: exact-prompt B1→B2 top1 among all 20 heldout B2 candidates; same 200 controls; B1/B2 heldout cosine representational similarity (train-only centered) with row-label permutation controls; nearest-neighbor graph overlap; matched cosine, token lengths and cost. A positive RSA alone does not count as primary gain. No repeated split, no tuning, no threshold changes.

Results: `PARAPHRASE_PROXY_SIGNAL` only if all three primary conditions pass, else `NO_PARAPHRASE_PROXY_SIGNAL`; error preserves original raw and negative gates. Even success establishes only offline frozen-state source retrieval on synthetic paraphrases, NOT B3 L1 utility, B3 L2 receiver injection, actual C3/JEF task accuracy, JEPA training or permission to activate a bridge.
